# K日程（K Agenda）

> **支持范围**：目前仅支持北航系统。

一个面向 **Android 8.0（API 26）及以上** 的非官方课表 / 日程工具：登录学校教务系统，抓取课表并提供
日 / 周 / 月视图、本地日程与计划管理、图片导出、课前提醒、桌面小组件与常驻状态通知；支持 中文 / English / Français 切换。

> ⚠️ 本应用是非官方个人工具，仅供学习与个人便利使用。账号密码仅保存在本机
> （Android Keystore 加密），不会上传到任何第三方服务器。

## 二、制作/运行本应用需要安装的环境

1. **Android Studio**（最新稳定版即可，如 Ladybug 2024.2+ / Meerkat）
   - 自带 JDK 21（工程使用 JDK 17 语言级别，无需单独装 JDK）
   - Kotlin / Compose 支持已内置，**不需要额外安装 IDE 插件**
2. **Android SDK**
   - `SDK Platform 35 (Android 15)` ← 必须（仅编译需要；运行设备最低支持 Android 8.0）
   - `Build-Tools 35.0.x`、`Platform-Tools (adb)`、`Android SDK Command-line Tools`（默认勾选的都保留即可）
   - 在 Android Studio → Settings → Languages & Frameworks → Android SDK 中勾选安装
3. **运行设备**
   - 真机：Android 8.0+ 手机，打开开发者选项 + USB 调试；
   - 或模拟器：Device Manager 中下载 **Android 8.0 及以上（API 26+）** 系统镜像（Google APIs x86_64；建议较新版本，体验更佳）
4. （可选，Windows）`Google USB Driver`：手机连不上电脑时在 SDK Manager → SDK Tools 中安装
5. （可选）Git：版本管理

**不需要**：NDK、CMake、Python、Node.js、ADB 以外的手机助手工具。
本工程的所有第三方库都由 Gradle 自动下载，无需手动安装任何依赖。

### 工程内依赖库清单（由 Gradle 自动获取）

> 因此采用“WebView 保持真实登录会话 + 页面内脚本读取数据”的方案，最贴近网页行为、最稳。

## 三、编译运行步骤

1. Android Studio → **Open** → 选择本 `KAgenda` 目录（不是 `s` 根目录）。
2. 等待 Gradle Sync（首次会自动下载依赖；若提示缺少 Gradle Wrapper，按提示
   “Create wrapper”或使用 Android Studio 自带的 Gradle 同步即可）。
3. 连接 Android 8.0+ 设备或启动任意 API 26+ 模拟器，点击 **Run ▶**。
4. 首次启动会请求通知权限（用于课前提醒），允许即可。
5. 想体验更流畅的性能版，可命令行构建 Release 包（已配置 R8 压缩 + 资源收缩 + debug 签名，可直接安装）：
   ```
   .\gradlew.bat assembleRelease
   ```
   产物：`app\build\outputs\apk\release\app-release.apk`（体积远小于调试包，帧率与启动明显更快；与调试包同签名，可相互覆盖安装）。

## 四、使用说明

1. 打开「设置」页 → 输入**学号**和**密码** → 点「保存并同步」。
   - 应用会在后台打开登录页自动填写并提交；如遇验证码等无法自动处理的步骤，请稍后重试。
   - （原「网页登录」手动入口已按需求隐藏，相关代码保留在项目中未删除，恢复方法见 `HIDDEN_FEATURES.md`）
2. 同步成功后：
   - 「日视图」：顶部日期条切换本周任意一天，查看当天课程卡片（时间、节次、教师、教室、周次）；
   - 「周视图」：查看整周网格，点击课程块查看详情；
   - 两个页面右上按钮可分别把**日课表 / 周课表**保存为图片到系统相册（`Pictures/K日程`）。
3. 「设置 → 课前提醒」：开关提醒、选择提前分钟数。
   - 建议点「去授权」打开系统的精确闹钟开关，否则提醒可能延迟最多 10 分钟；
   - 建议再点「去解除」放开后台电池限制（显示“后台限制：已解除”后，应用切到后台时提醒更可靠）；
   - 通知权限未开启时点「开启通知」。

## 五、工作原理（代码导读）

```
app/src/main/java/com/kstudio/agenda/
├─ KebiaoApp.kt                 应用入口：通知渠道、周期任务、缓存引导
├─ data/
│  ├─ WebScheduleEngine.kt      无界面 WebView：登录 → 轮询页面 → 抓取 → 返回课表
│  ├─ JsScripts.kt              注入脚本：XHR/fetch 挂钩、登录表单自动填充、课表 DOM 提取
│  ├─ ScheduleParser.kt         解析提取结果（主：DOM JSON；兜底：接口 JSON 启发式解析）
│  ├─ ScheduleRepository.kt     仓库：缓存、同步状态、提醒调度入口（单例）
│  ├─ SettingsStore.kt          设置与账号（DataStore）
│  ├─ CacheStore.kt             课表缓存 + 接口原始数据留档
│  └─ CryptoManager.kt          密码的 Keystore AES-GCM 加密
├─ model/
│  ├─ PeriodTimes.kt            14 节课的时间表（08:00 … 22:15）
│  ├─ Models.kt                 Course / WeekSchedule 模型 + 周次解析
│  └─ CoursePalette.kt          课程配色
├─ notif/                       提醒：AlarmManager 调度、通知、开机恢复、WorkManager 兜底
├─ export/
│  ├─ ScheduleImageRenderer.kt  Canvas 绘制日/周课表图片
│  └─ ImageExporter.kt          MediaStore 写入相册
└─ ui/                          Compose 界面：Main(导航) / Day / Week / Settings / WebLogin
```

- **同步流程**（`WebScheduleEngine`，分 4 阶段，每一步都有日志）：
  1. 直接打开教务系统首页（已有会话时立即可抓）；
  2. 若出现“网络异常”页 / 登录表单 / 无课表 → 打开学校统一身份认证登录页，
     探测登录表单（含同源 iframe 内的 `#unPassword` / `#pwPassword`），自动填写并点击登录；
  3. 等待离开登录页（识别错误提示，如“密码错误”则提示用户）；
  4. 重新打开首页等待“我的课表”渲染，注入 `EXTRACT` 抓取。
- **抓取与解析**：页面加载时注入 `HOOKS`（挂钩 XHR/fetch，按 URL 匹配
  `getMyScheduleDetail` / `getSections` / `schoolCalendars` 等关键接口，
  同时捕获请求体与响应体）；解析优先级：接口响应 `datas.arrangedList`
  （字段：courseName / courseCode / byCode / dayOfWeek / beginSection /
  endSection / cellDetail）> DOM 提取（类名前缀匹配 + flex 推算节次）。
- **超时保护**：单次 JS 调用 5 秒超时、各阶段 20~50 秒超时、整次同步 4 分钟硬超时，
  不会再出现一直“正在同步”。
- **整学期抓取（新增）**：当前周抓取成功后，会从捕获的接口请求中提取 `termCode/campusCode`，
  在页面上下文内按周重放 `getMyScheduleDetail.do`（第 1~20 周，连续 4 周为空则提前结束），
  合并为整个学期的课表；日/周视图可用“‹ 上一周 / 下一周 ›”切换，课前提醒也覆盖整个学期。
- **节次换算**：`3-4节` → `09:50-11:25`（使用 `PeriodTimes` 中的作息表）。
- **提醒**：依据缓存的周次信息推算未来 7 天每节课的开始时间，提前 N 分钟触发通知；
  触发时再次校验开关，避免重新开启后旧闹钟打扰。
| 提示“需要登录” | 统一认证出现验证码/二次确认时无法自动完成（原「网页登录」手动入口已隐藏），请稍后重试 |
| 同步失败但网页正常 | 学校页面结构更新，调整 `JsScripts.kt` 中的类名前缀或正则即可；也可以把「运行日志」分享给开发者定位 |
| 一直“正在同步” | 已加多层超时保护（单次 JS 5 秒 / 阶段 20~50 秒 / 整次 4 分钟）；如仍出现，请查看日志中的最后阶段

> 说明：网页一次只渲染“当前教学周”的课表（切换其他周需要点击页面上的按钮）。
> 应用抓取当前周即可满足日/周视图与提醒需求（提醒会按课程周次自动推算未来日期）；
> 如需抓取任意周，可复用捕获到的接口请求（`{termCode, campusCode, type:'week', week:N}`）扩展。

## 六、已知限制与排查

| 现象 | 说明 / 处理 |
| --- | --- |
| 登录后提示“需要登录” | 统一认证出现验证码/二次确认时无法自动完成（原「网页登录」入口已隐藏），请稍后重试 |
| 同步失败但网页正常 | 学校页面结构更新，调整 `JsScripts.kt` 中的类名前缀或正则即可（提取脚本已尽量使用前缀匹配与文本规则，抗改版） |
| 提醒不精确 / 后台收不到提醒 | 到 设置 → 课前提醒：点「去授权」允许“闹钟和提醒”权限；点「去解除」放开电池优化限制。部分厂商系统还需在系统设置中允许应用“自启动 / 后台运行” |
| 只同步了“当前教学周” | 页面默认展示当前周网格，应用抓取的即为该周；换周后可再次刷新 |
| 周次显示为空 | 页面未提供周次（如临时课程），此时提醒默认按每周处理 |
